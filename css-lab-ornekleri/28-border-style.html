Kenarlık Stili (border-style)

Bu özellik aşağıdaki şekillerde kenarlık tipi tanımlamaya izin verir.

dashed (çizgili)

solid (düz, boşluksuz)

double (çift)

groove (yivli,çukur)

dotted (noktalı)

ridge (sırt,çıkıntılı)

inset (çukur gölgeleme)

outset (çıkıntı gölgeleme)

none (yok, hiçbiri)

hidden (gizlenmiş)

mixed (karma, hepsinden)

Her yön farklı: üst solid, sağ dashed, alt dotted, sol double
